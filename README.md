### Cómo trabajamos

- **Rendimiento, accesibilidad y SEO al máximo.** Nuestra propia web puntúa 98–100 en PageSpeed Insights y cumple WCAG AA.
- **Diseño hecho para cada cliente,** sin plantillas genéricas: cada proyecto parte de su marca.
- **Código limpio y documentado,** preparado para crecer y para que el cliente pueda gestionarlo.
